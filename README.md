## Deskripsi Singkat
**WashFlow** adalah aplikasi *mobile* berbasis Android untuk manajemen operasional dan pemesanan jasa laundry UMKM. Aplikasi ini memfasilitasi interaksi antara **Pelanggan** (memilih paket layanan, membuat pesanan, mengunggah bukti transfer, melacak status cucian, dan memberikan ulasan) dan **Admin** (mengelola katalog paket layanan, memvalidasi pembayaran, serta memperbarui status pengerjaan cucian). Sistem dibangun menggunakan Jetpack Compose dengan arsitektur MVVM yang terintegrasi ke *backend* REST API, basis data PostgreSQL, serta penyimpanan *file* lokal untuk bukti pembayaran.
